

# Images Produits Ultra-Premium "Haute Joaillerie CBD"

Creer des images produits d'un niveau jamais vu dans l'industrie CBD - style campagne publicitaire de luxe type Rolex, Cartier ou parfum Chanel.

## Direction Artistique Detaillee

### L'Environnement

```text
┌────────────────────────────────────────────────────────────────┐
│                    FOND NOIR PROFOND (#000000)                 │
│                                                                │
│         ✨  Particules dorees flottantes subtiles  ✨          │
│                                                                │
│                    ╔═══════════════════╗                       │
│                    ║                   ║                       │
│                    ║   🌿 FLEUR CBD    ║ ← Eclairage 3 points  │
│                    ║                   ║   avec rim light dore │
│                    ╚═══════════════════╝                       │
│        ─────────────────────────────────────────               │
│        ▓▓▓▓▓▓▓▓ TABLE NOIR MAT ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓               │
│        ░░░░░░░░ avec reflet subtil ░░░░░░░░░░░░░               │
│        ✦ ✦ ✦  Paillettes dorees dispersees ✦ ✦ ✦              │
└────────────────────────────────────────────────────────────────┘
```

### Elements Cles

| Element | Description |
|---------|-------------|
| **Table** | Surface noir mat visible, comme dans les photos de montres de luxe |
| **Reflet** | Reflet doux de la fleur sur la table (effet miroir subtil) |
| **Paillettes** | Particules dorees dispersees sur la table autour du produit |
| **Eclairage** | 3 sources lumineuses studio : key light + fill light + rim light dore |
| **Atmosphere** | Particules dorees flottantes dans l'air (effet poussiere d'or) |
| **Fleur** | IDENTIQUE a l'originale, mise en valeur comme un diamant |

## Prompt IA Ultra-Detaille

```text
LUXURY CANNABIS PHOTOGRAPHY - HAUTE JOAILLERIE STYLE

Transform this CBD flower into an ultra-premium luxury product photograph 
worthy of a Cartier or Rolex advertising campaign.

ENVIRONMENT:
- Deep black background (#000000) with subtle gradient
- Matte black reflective table/surface visible at the bottom
- The flower sits ON the table surface, not floating
- Subtle mirror reflection of the flower on the table

LIGHTING:
- Professional 3-point studio lighting setup
- Key light from top-right creating dramatic shadows
- Fill light from left softening shadows
- Golden rim light (back lighting) creating a luxurious gold outline around the flower
- Subtle golden ambient glow

GOLDEN ELEMENTS:
- Fine gold dust particles scattered on the matte black table surface
- Delicate floating gold particles in the air (bokeh effect)
- Golden highlights on trichomes making them sparkle like diamonds
- Subtle gold lens flare touches

FLOWER:
- Keep the EXACT same flower from the original photo
- Do NOT modify the flower shape, color or structure
- Only enhance lighting and add the luxury environment
- Make trichomes shimmer like precious crystals

STYLE:
- Ultra high-end luxury cannabis boutique
- Jewelry-grade product photography
- Fashion magazine editorial quality
- NEVER SEEN BEFORE aesthetic
- NO TEXT, NO WATERMARK, NO LABELS

This should look like a product that costs 1000€ per gram - 
pure luxury, exclusivity, and refinement.
```
